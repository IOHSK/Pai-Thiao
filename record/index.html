Pai Thiao 소리 녹음

사이트에서 들리는 태국어 소리를 하나씩 녹음해요. 목록은 구간과 과 순서로 나오고, 아직 녹음하지 않은 첫 말에서 시작해요. 녹음은 이 브라우저에 저장되니 여러 번에 나눠서 해도 되고, 일부만 올려도 돼요. 녹음이 없는 말은 기기 음성으로 대신 나와요.

  • 사람 목소리로 녹음해도 되고 AI 목소리로 채워도 돼요. AI로 저장한 말도 나중에 녹음하면 사람 목소리로 바뀌어요.
  • 공손 어미가 붙는 말은 남성(ครับ)과 여성(ค่ะ, คะ) 두 가지로 따로 나와요. 사이트는 노란 버튼으로 고른 어미에 맞는 소리를 들려줘요. 남성 말은 남성 목소리로, 여성 말은 여성 목소리로 맞추면 자연스러워요.
  • 태국어는 성조가 뜻을 바꿔요. AI 목소리는 저장하기 전에 꼭 들어 보세요. 성조가 자꾸 틀리면 아래 설정에서 로마자 성조 표기를 AI에게 함께 전해 보세요.
  • 사이트의 천천히 듣기는 녹음을 0.75배로 늦춰 들려줘요. 녹음은 보통 빠르기나 조금 천천히로 하면 돼요.
  • 앞뒤 빈 소리와 음량은 도구가 자동으로 맞춰요.
  • 단축키: 스페이스 녹음 시작과 끝, P 다시 듣기, → 다음, ← 이전, A AI 목소리 만들기, S AI 목소리 저장

AI 목소리 설정

API 키 받는 법 (한 번만)
  1. aistudio.google.com에 Google 계정으로 로그인해요.
  2. Get API key를 누르고 Create API key로 키를 만들어요. 달토끼나 Buen Camino 녹음실에서 쓰던 키를 그대로 써도 돼요.
  3. 많이 만들 때는 무료 한도에 금방 걸릴 수 있어요. 그럴 때는 같은 화면에서 결제(유료 등급)를 켜면 돼요. 한도에 걸리면 도구가 잠깐 기다렸다가 다시 시도해요.
  4. 키를 위 칸에 붙여 넣고 저장해요. 키는 이 브라우저에만 남고, 코드나 저장소, 내려받는 zip에는 들어가지 않아요.
녹음 AI 이미 사이트에 올라간 것 들어 보고 확인할 것 너무 긴 AI 소리

남은 말 AI로 한꺼번에 채우기

위에서 고른 구간과 어미 안에서, 아직 녹음도 AI도 없는 말을 차례로 만들어 저장해요. 남성 말은 남성 목소리, 여성 말은 여성 목소리로 만들어요. 만든 소리가 말에 비해 너무 길면(AI가 지시문을 읽은 경우) 모델과 지시문을 바꿔 가며 여섯 번까지 다시 만들어요. 그래도 길면 마지막 말만 잘라 내서 저장하고 "들어 보고 확인할 것"으로 표시해요. 한 모델이 하루 한도에 걸리면 다른 모델로 넘어가요. 분당 한도에 맞춰 천천히 진행하고, 하루 한도에 걸리면 멈춰요. 중간에 멈춰도 만든 것은 남아요. 다 채운 뒤 몇 개를 골라 들어 보고, 성조가 이상한 것만 다시 만들면 돼요.

사이트에 올리기

zip을 내려받아 저장소 맨 위(index.html이 있는 곳)에 풀면 assets/audio/ 폴더에 소리 파일과 manifest.js가 들어가요. zip에는 버전을 하나 올린 sw.js도 들어 있어서, 휴대전화에 저장해 둔 사이트도 새 소리를 받아요. 이미 사이트에 올라간 소리 목록도 manifest에 함께 들어가니, 이번에 만든 것만 있어도 괜찮아요. 올린 뒤 몇 분 지나 새로고침하면 사이트에서 녹음한 소리가 나와요.
